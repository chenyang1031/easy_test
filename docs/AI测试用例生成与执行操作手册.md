## 1. 概述与前置依赖

### 1.1 功能定位

| 模块 | 功能说明 |
| --- | --- |
| **AI大模型管理** | 配置AI模型供应商（如DeepSeek、智谱GLM、本地Qwen等），管理API密钥、模型参数、提示词模板 |
| **提示词模板管理** | 管理AI生成测试用例时使用的提示词模板，支持变量占位符、导入/导出 |
| **AI规则管理** | 管理AI生成测试用例时的规则配置，按分类组织，支持导入/导出 |
| **AI批量生成** | 在API资产管理中选中接口，一键提交AI批量生成测试用例 |
| **AI草稿箱** | 查看AI生成的测试用例草稿，支持选中导入到测试套件 |
| **AI生成记录** | 查看所有AI调用的历史记录，包括请求Prompt、AI返回内容、耗时、状态等 |
| **测试用例执行** | 对测试用例选择环境执行，查看请求/响应详情 |
| **测试套件执行** | 对测试套件批量执行，查看汇总结果和各用例详情 |

### 1.2 前置依赖（必读）

在使用AI相关功能前，需先完成以下配置：

| 依赖菜单 | 说明 |
| --- | --- |
| **项目** | 在「项目」菜单创建项目。API资产和测试用例均按项目归属 |
| **环境** | 在「环境」菜单为项目配置运行环境（含域名、变量），测试执行时必须选择环境 |
| **API资产管理** | AI生成基于API资产中的接口定义，需先导入或创建接口 |

**路径：**
- 项目：左侧导航 → 项目 → 创建项目
- 环境：左侧导航 → 环境 → 创建环境（需关联项目）
- API资产管理：左侧导航 → API资产管理

## 2. AI大模型管理

### 2.1 入口与布局

- **入口**：左侧导航 → **AI大模型管理**
- **布局**：顶部工具栏（新增/刷新） + 列表表格

### 2.2 列表操作

列表展示以下字段：供应商名称、供应商类型（OpenAI兼容/智谱AI/DeepSeek/自定义）、模型名称、API地址、启用状态、是否默认、更新时间。

**操作按钮：**

| 操作 | 说明 |
| --- | --- |
| **新增供应商** | 打开表单弹窗配置新的AI模型 |
| **编辑** | 修改现有供应商配置 |
| **删除** | 删除供应商（确认后不可恢复） |
| **设为默认** | 将当前供应商设为默认，AI生成时自动选用 |
| **测试连接** | 发送连通性测试请求，验证配置是否正确 |

### 2.3 新增/编辑供应商

点击「新增供应商」或「编辑」打开弹窗，填写以下配置：

#### 2.3.1 基础信息

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| **供应商名称** | 自定义名称，如"DeepSeek-V3"、"本地Qwen" | 是 |
| **供应商类型** | OpenAI兼容 / 智谱AI / DeepSeek / 自定义 | 是 |
| **API基础地址** | 服务完整地址，如 `https://api.deepseek.com` 或 `http://192.168.0.147:30000/v1` | 是 |
| **API路径** | 默认为 `/chat/completions`，OpenAI兼容接口通常不变 | 否 |
| **模型名称** | 模型标识，如 `deepseek-chat`、`glm-4-plus`、`Qwen/QwQ-32B` | 是 |
| **API Key** | 密钥（Bearer Token）。**本地模型无需密钥可留空** | 否 |

#### 2.3.2 模型参数

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| **温度** | 采样温度 0-2，越高越随机 | 0.7 |
| **最大Token** | 单次请求最大输出Token数 | 4096 |
| **超时时间(秒)** | AI服务调用超时时间 | 180 |

#### 2.3.3 提示词配置

| 字段 | 说明 |
| --- | --- |
| **系统提示词** | 发送给模型的系统角色指令，默认："你是一个专业的API测试工程师..." |
| **响应解析路径** | JSON路径，用于从响应中提取用例数组，默认为 `choices.0.message.content` |
| **提示词模板** | 用户提示词模板，使用 `{变量名}` 占位符，详见下方说明 |

**提示词模板支持以下变量：**
- `{method}` - 请求方法
- `{url}` - 请求URL
- `{headers}` - 请求头
- `{body_schema}` - 请求体结构
- `{rules_text}` - 测试规则
- `{case_type}` / `{casetype_desc}` - 用例类型
- `{api_name}` / `{api_desc}` - 接口名称和描述
- `{params}` - 请求参数
- `{body_format}` - 请求体格式
- `{request_body}` - 请求体
- `{response_schema}` - 响应结构
- `{error_codes}` - 错误码
- `{auth_config}` - 认证配置

### 2.4 测试连接

配置完成后，点击「测试连接」按钮验证配置是否可用：
- 系统会使用当前配置调用AI服务（连通性检查类型）
- 成功：显示"连接测试通过"及用例预览
- 失败：显示具体错误信息（如HTTP 400、超时、认证失败等）

### 2.5 添加本地模型示例

以本地Docker部署的Qwen/QwQ-32B为例：

```
供应商名称：本地Qwen
供应商类型：OpenAI兼容
API基础地址：http://192.168.0.147:30000/v1
API路径：/chat/completions
模型名称：Qwen/QwQ-32B
API Key：（留空）
温度：0.7
最大Token：4096
超时时间(秒)：180
```

**注意**：本地模型的API基础地址需填写完整协议+IP+端口+路径前缀，确保平台服务器能访问该地址。API Key为空时，请求头不会携带Authorization字段。

## 5. AI批量生成测试用例

### 5.1 入口

- **入口**：左侧导航 → **API资产管理** → 顶部「AI批量生成」按钮

### 5.2 操作步骤

1. **选中接口**：在API资产列表中勾选要生成测试用例的接口（可多选）
2. **点击「AI批量生成」**：打开生成配置弹窗
3. **选择AI模型**：从已配置的AI模型中选择（自动选中默认模型）
4. **选择用例类型**：

| 类型 | 说明 |
| --- | --- |
| 接口测试（通用） | 综合性的接口功能测试用例 |
| 参数校验 | 参数合法性、必填项覆盖 |
| 业务逻辑 | 业务流程场景覆盖 |
| 异常处理 | 异常场景、错误处理覆盖 |
| 边界值 | 参数边界值覆盖 |
| 安全 | 安全测试场景 |
| 性能 | 性能测试场景 |

5. **选择提示词模板**：选择要使用的提示词模板（自动选中默认模板）
6. **选择应用规则**：可选多条规则，不选则仅按默认规则生成
7. **点击「开始生成」**：提交生成任务

### 5.3 生成流程

1. 提交后系统为每个接口创建一条**AIGenerationRecord**（状态：生成中）
2. **Celery异步任务**在后台逐个调用AI服务
3. AI返回结果经解析后生成**测试用例草稿**
4. 按接口维度归入**草稿组**，存入**AI草稿箱**
5. 可在**AI生成记录**页面查看每条的生成状态和详情

### 5.4 生成完成后

- 弹窗提示"已提交生成任务"并提供跳转到**AI生成记录**的入口
- AI生成记录中可查看每条记录的生成进度（生成中/成功/失败）
- 生成成功的用例进入**AI草稿箱**，可在草稿箱中查看并导入

## 6. AI草稿箱

### 6.1 入口与布局

- **入口**：左侧导航 → **AI草稿箱**
- **布局**：左侧草稿组列表 + 右侧草稿详情（左右分栏）

### 6.2 草稿组列表（左侧）

以"草稿组"为单位组织，每个AI生成批次为一个草稿组。

**展示信息：** 组名称、草稿条数、所属项目、创建时间、导入状态

**导入状态：**

| 状态 | 说明 |
| --- | --- |
| 待导入 | 尚未导入任何草稿 |
| 部分导入 | 部分草稿已导入为测试用例 |
| 全部导入 | 所有草稿均已导入 |

**操作：**
- 点击草稿组加载右侧草稿列表
- 支持按项目筛选
- 支持分页

### 6.3 草稿列表（右侧）

展示草稿的详细信息：

| 列 | 说明 |
| --- | --- |
| 用例名称 | AI生成的用例名称 |
| 方法 | 请求方法（GET/POST等） |
| URL | 请求URL |
| 导入状态 | 待导入/已导入/失败（已导入的草稿不可再次导入） |

**操作：**

| 操作 | 说明 |
| --- | --- |
| **查看** | 弹窗显示用例详情：名称、描述、请求方法、URL、请求头、请求参数、请求体、校验规则 |
| **导入选中** | 将选中的草稿导入为正式测试用例 |
| **删除选中** | 删除选中的草稿（已导入的不可删除） |
| **删除组** | 删除整个草稿组及所有草稿（含已导入草稿的组不可直接删除） |

### 6.4 导入草稿

1. 勾选要导入的草稿（可多选）
2. 点击「导入选中」打开导入弹窗
3. 选择导入方式：

| 方式 | 说明 |
| --- | --- |
| **不关联套件** | 仅创建测试用例，不关联到任何测试套件 |
| **关联已有测试套件** | 选择已有测试套件，导入的用例自动关联到该套件 |
| **创建新的测试套件** | 输入新套件名称，自动创建套件并关联导入的用例 |

4. 点击「确认导入」执行导入
5. 导入结果在弹窗和页面中反馈：成功条数、失败条数

## 7. AI生成记录

### 7.1 入口与布局

- **入口**：左侧导航 → **AI生成记录**
- **布局**：筛选栏 + 列表表格 + 详情弹窗

### 7.2 筛选与搜索

| 条件 | 说明 |
| --- | --- |
| **模型筛选** | 按AI模型供应商过滤 |
| **开始日期** | 按创建日期起始范围过滤 |
| **结束日期** | 按创建日期结束范围过滤 |
| **关键词搜索** | 搜索请求Prompt内容 |

### 7.3 列表字段

| 列 | 说明 |
| --- | --- |
| 模型 | AI模型供应商名称（旧版参数配置标记为"旧版参数配置"） |
| 接口 | 接口名称、请求方法、请求URL |
| 用例类型 | 接口测试/参数校验/业务逻辑等 |
| 数量 | AI返回的用例条数 |
| 状态 | 生成中（黄色标签）/ 成功（绿色）/ 失败（红色） |
| 调用人 | 提交生成的用户 |
| 耗时 | AI调用耗时，如 3.2s、1m25s |
| 时间 | 创建时间 |
| 操作 | 详情 / 删除 |

### 7.4 详情弹窗

点击「详情」查看完整的AI调用信息：

**基本信息：**
- 模型、提示词模板、接口、用例类型、耗时、状态、返回数量
- 错误信息（仅失败时显示）

**请求Prompt：** AI调用时发送的完整提示词内容，支持一键复制

**AI返回：** AI返回的原始内容（JSON格式），支持语法高亮和复制
- 超过20KB时默认折叠展示，支持展开全部
- JSON语法高亮：键（蓝色）、字符串（橙色）、数字（绿色）、布尔值/null（蓝色）

### 7.5 删除与批量删除

- **单条删除**：点击行操作中的「删除」按钮确认删除
- **批量删除**：勾选多条记录后点击「删除选中」批量删除

### 7.6 分页

- 底部显示总条数、当前页、总页数
- 支持每页条数切换：10/20/30/50
- 支持上一页/下一页

## 8. 测试用例执行

### 8.1 入口

- **入口**：左侧导航 → **测试用例** → 点击用例行的「运行」按钮

### 8.2 执行配置

1. **选择测试环境**：选择该用例执行所需的环境（含base_url、变量等配置）
2. 页面展示用例详情：项目、请求方式、URL、预期状态码、描述
3. 自动拼接完整URL（环境base_url + 用例URL）

### 8.3 执行结果

点击「立即运行」后，系统：
1. 创建TestRun记录
2. 执行测试用例（发送HTTP请求）
3. 记录执行结果：

| 结果字段 | 说明 |
| --- | --- |
| 状态 | 通过（passed）/ 失败（failed） |
| 响应状态码 | HTTP响应状态码 |
| 响应时间 | 请求响应耗时 |
| 请求头 | 实际发送的请求头 |
| 请求体 | 实际发送的请求体 |
| 响应头 | 服务端返回的响应头 |
| 响应体 | 服务端返回的响应体 |
| 错误信息 | 失败时的错误详情 |
| 提取参数 | 从响应中提取的参数 |
| 校验结果 | 各校验规则的通过情况 |

## 9. 测试套件执行

### 9.1 入口

- **入口**：左侧导航 → **测试套件** → 点击套件行的「运行」按钮

### 9.2 执行配置

1. **运行名称**：自定义本次运行的名称（可选）
2. **选择默认环境**：为套件中所有用例选择默认执行环境
3. 页面展示套件包含的用例列表（顺序、名称、方法、URL）

### 9.3 执行流程

1. 系统创建TestRun记录（关联测试套件）
2. 按顺序逐个执行套件中的测试用例
3. 每个用例独立记录TestResult
4. 汇总执行结果

### 9.4 执行结果

**套件级别：**
- 状态：完成（completed）/ 失败（failed）
- 通过用例数、失败用例数

**用例级别：**
- 状态、响应状态码、响应时间
- 请求头、请求体、响应头、响应体
- 校验结果、提取参数、错误信息

## 11. 典型工作流

### 11.1 从零开始使用AI生成测试用例

1. **AI大模型管理**：配置AI模型供应商（如DeepSeek、智谱等）
2. **提示词模板管理**：创建或修改提示词模板
3. **AI规则管理**：创建测试生成规则（可选）
4. **API资产管理**：确保已有API接口资产
5. **AI批量生成**：选中接口 → 选择模型/模板/规则 → 提交生成
6. **AI生成记录**：查看生成进度和结果
7. **AI草稿箱**：查看生成的草稿 → 导入到测试套件
8. **测试套件执行**：选择环境 → 执行套件 → 查看结果

### 11.2 配置本地大模型

1. 在「AI大模型管理」点击「新增供应商」
2. 填写配置：
   - 供应商名称：如"本地Qwen"
   - 供应商类型：OpenAI兼容
   - API基础地址：`http://192.168.0.147:30000/v1`
   - API路径：`/chat/completions`
   - 模型名称：`Qwen/QwQ-32B`
   - API Key：留空
3. 点击「测试连接」验证配置
4. 设为默认（可选）

### 11.3 生成用例并导入套件

1. 在「API资产管理」勾选多个接口
2. 点击「AI批量生成」，配置模型、用例类型、模板、规则
3. 提交后等待AI生成完成（可在「AI生成记录」查看进度）
4. 进入「AI草稿箱」，选择对应的草稿组
5. 勾选要导入的草稿，点击「导入选中」
6. 选择「关联已有测试套件」或「创建新的测试套件」
7. 确认导入，用例自动进入测试套件
8. 在「测试套件」中执行该套件

### 11.4 单接口快速生成与执行

1. 在「API资产管理」找到目标接口
2. 点击「AI批量生成」只选中该接口
3. 提交生成后进入「AI草稿箱」
4. 导入草稿到测试套件
5. 在「测试套件」中执行该套件 → 查看执行结果

### 11.5 排查AI生成失败

当AI生成失败时，通过以下步骤排查：

1. 进入「AI生成记录」找到失败的记录
2. 查看「详情」中的**错误信息**
3. 确认AI模型供应商配置是否正确：API地址可达、Key有效
4. 确认提示词模板是否包含必要的变量占位符
5. 在「AI大模型管理」点击「测试连接」直接验证配置
6. AI返回原始内容可在详情中查看，判断是否为格式问题

### 11.6 迭代优化生成效果

1. **调整提示词模板**：修改模板中的描述和要求，引导AI生成更符合需求的用例
2. **补充生成规则**：在「AI规则管理」中增加针对性的规则
3. **切换模型供应商**：不同模型在不同场景下的表现可能不同
4. **调整模型参数**：如适当降低温度使输出更稳定

## 附录：常见问题

### AI调用返回400错误

**可能原因：**
- API基础地址或路径配置错误
- API Key为空但服务端要求认证（或非空但格式不正确）
- 模型名称不存在

**解决方案：**
- 检查「AI大模型管理」中的API地址配置
- 本地模型若无需认证，确保API Key留空
- 确认模型名称与服务端支持的一致

### AI生成但没有返回用例

**可能原因：**
- 提示词模板过于复杂或要求不明确
- 响应解析路径配置不正确
- 模型输出的JSON格式不符合预期

**解决方案：**
- 在「AI生成记录」查看AI返回的原始内容
- 调整提示词模板，明确要求以纯JSON格式返回
- 检查响应解析路径是否匹配AI返回结构

### 草稿导入失败

**可能原因：**
- 草稿中某些字段不符合测试用例表单校验规则
- 目标测试套件已被删除或无权限

**解决方案：**
- 在草稿箱查看导入失败的草稿详情，根据错误信息调整
- 确认目标套件存在且有操作权限
