## 🔴 严重 (Critical) 问题

### 1. 可访问性 — 无焦点状态指示 ✅ 已修复
**文件**: `templates/base.html`、所有页面  
**问题**: 侧边栏 `nav-link`、卡片、表格行交互时缺少可见的 `:focus-visible` 样式。键盘用户无法感知当前焦点位置。  
**UX 影响**: 无法通过键盘导航操作 — 违反 WCAG 2.1 SC 2.4.7。  
**修复**:
```css
.nav-link:focus-visible,
.card:focus-visible,
.btn:focus-visible {
  outline: 3px solid var(--primary-color);
  outline-offset: 2px;
}
```

### 2. 表单 — 请求头表格缺少 `<label>` 关联 ✅ 已修复
**文件**: `templates/test_manager/test_case_form.html`（第 704-724 行）  
**问题**: Headers/Params/Extract/Validation 表格中，`<input>` 使用 `placeholder` 代替 `<label>`，不满足 WCAG 1.1.1。屏幕阅读器无法识别输入用途。  
**影响**: 无法使用读屏软件填写复杂的 API 请求表单。  
**修复**: 为每个表格输入添加 `aria-label`：
```html
<input type="text" class="form-control header-key"
       aria-label="请求头名称"
       placeholder="Key">
```

### 3. 颜色对比度不足 — 状态 Badge 文字 ✅ 已修复
**文件**: `templates/base.html`（第 187-195 行）  
**问题**: `.badge.bg-success` 使用 `color: var(--success-color)`（`#4cc9f0`） 在透明背景上对比度仅为 **~2.8:1**，远低于 4.5:1 标准。  
**影响**: 通过/失败状态在小字号下几乎不可读。  
**修复**:
```css
.badge.bg-success {
  color: #0a7e9c; /* 更深的青色 */
}
```

## 🟠 高优先级 (High) 问题

### 4. 不一致的明暗模式 — 无深色模式支持 ✅ 已修复
**所有页面**  
**问题**: 整个应用只有浅色主题（`background-color: #f5f7fb`）。无 `prefers-color-scheme: dark` 媒体查询。夜间使用时刺眼。  
**UX 影响**: 测试工程师常在暗光环境工作，缺少深色模式导致眼部疲劳。  
**修复**: 在 `base.html` 添加 CSS 变量系统，支持双模式切换。

### 5. 无骨架屏 / 加载状态 ✅ 已修复
**文件**: `templates/test_manager/dashboard.html`、`templates/test_manager/mock_data_vue.html`  
**问题**: Vue 挂载点 `<div id="app">` 和 `<div id="environment-list-mount">` 仅在 JS 渲染后才显示内容，加载期间用户只看到空白区域。  
**UX 影响**: 页面呈现"空屏"感，用户可能以为页面卡死。  
**修复**:
```css
#app::before {
  content: "加载中...";
  display: flex;
  justify-content: center;
  padding: 40px;
}
```

### 6. 模板混合架构的视觉断裂 🔄 部分缓解
**文件**: 几乎所有列表页  
**问题**: 项目混用 Bootstrap 模板渲染（`project_list.html`、`test_case_list.html`） 和 Vue/Element Plus 组件（`environment_list.html`、`dashboard.html`）。两套 UI 系统的视觉风格完全不同（Bootstrap 的圆角卡片 vs Element Plus 的扁平设计），用户在不同页面间切换时体验割裂。  
**UX 影响**: 导航菜单中 Vue 页面和 Django 模板页面跳转时视觉风格突变，用户感到困惑。  
**修复**: 统一使用一套组件库，或至少对齐视觉 token（圆角、间距、颜色变量）。

### 7. 表单验证反馈不够直观 ✅ 已修复
**文件**: `templates/test_manager/test_case_form.html`  
**问题**: 表单错误显示在页面顶部的 `<ul>` 中（第 15-27 行），未使用 `aria-describedby` 关联到具体字段。用户需要自行查找错误字段。  
**UX 影响**: 长表单（测试用例编辑）错误定位困难。  
**修复**: 在错误输入上添加 `is-invalid` 类和 `aria-describedby`，使错误与字段内联。

### 8. 移动端导航不可用 ✅ 已修复
**文件**: `templates/base.html`（第 96-113 行）  
**问题**: 侧边栏在 `767.98px` 以下使用 `translateX(-100%)` 隐藏，但主页菜单组多达 **26 项**，移动端展开后高度溢出视口且无粘性滚动。  
**UX 影响**: 手机上无法合理使用导航。  
**修复**: 移动端优先展示常用项，将次级项折叠到"更多"菜单中。

## 🟡 中优先级 (Medium) 问题

### 9. 侧边栏菜单 collapsed 逻辑过于庞大 ✅ 已修复
**文件**: `templates/base.html`（第 431-438 行）  
**问题**: `collapsed` 类判断条件包含 **28 条路径检查**（一行超 2000 字符）。极易出错，维护成本极高。  
**UX 影响**: 用户点击导航项后，侧边栏可能无法正确展开/高亮当前菜单。  
**修复**: 使用模板 tag 或 JavaScript 替代模板端的海量判断。

### 10. 分页组件样式不协调 ✅ 已修复
**文件**: `templates/pagination.html`（第 160-169 行）  
**问题**: 分页链接使用 `background-color: #343a40`（深灰色），而应用主体使用 `--primary-color: #4361ee`（蓝色）。分页样式与整体主题完全不一致。  
**UX 影响**: 视觉割裂。  
**修复**:
```css
.modern-pagination .page-link {
  background-color: var(--primary-color);
  border-color: var(--primary-color);
}
```

### 11. "批量编辑"和"导出"功能为假占位 ✅ 已修复
**多处**: `test_case_form.html`、`test_report_detail.html`  
**问题**: 按钮点击弹出 `alert('批量编辑功能将在未来版本中实现')` 或 `alert('PDF导出功能即将上线')`。  
**UX 影响**: 用户点击按钮后只看到未实现的提示，体验沮丧。  
**修复**: 要么移除这些按钮，要么改为灰色禁用状态并添加 tooltip "即将上线"。

### 12. 删除确认方式不统一 ✅ 已修复
**文件对比**: `test_suite_list.html` 使用 BS Modal（第 216-236 行） vs `test_case_list.html` 使用 `onclick="return confirm(...)"` 原生弹窗  
**问题**: 相同操作（删除）在不同页面使用完全不同的确认方式。  
**UX 影响**: 用户需要适应不同交互模式。  
**修复**: 统一使用 BS Modal 确认。

### 13. 请求体/头的 JSON 输入区域缺少语法高亮 ✅ 已修复
**文件**: `templates/test_manager/test_case_form.html`  
**问题**: 请求体 JSON 使用 `<textarea>` 纯文本输入（第 224 行），无格式化/验证/高亮支持。  
**UX 影响**: 编写复杂 JSON 时易出错，且难以发现格式问题。  
**修复**: 集成 CodeMirror 或 Monaco Editor（项目中已有 codemirror.css/JS）。

### 14. 注册密码提示信息使用 `<ul>` 不当 ✅ 已修复
**文件**: `templates/auth/register.html`（第 58-65 行）  
**问题**: 密码规则列表使用 `ul` 但被屏幕阅读器解析为独立的"列表"，分散用户注意力。  
**UX 影响**: 阅读体验差。  
**修复**: 使用 `aria-label` 或改用 `div` 文字。

### 15. 仪表盘全 Vue 渲染导致无 JS 降级 ✅ 已修复
**文件**: `templates/test_manager/dashboard.html`  
**问题**: 页面只有一个 `<div id="app">` 挂载点，Vue JS 加载失败时用户看到空白页。  
**UX 影响**: JS 错误时完全无法使用。  
**修复**: 添加 `<noscript>` 提示和服务端渲染的至少一个摘要视图。

### 16. `lang` 属性不一致 ✅ 已修复
**文件**: `base.html` 使用 `lang="zh_hans"`（下划线格式，不规范） vs `base_auth.html` 使用 `lang="zh-CN"`  
**问题**: 两套 base 模板使用不同的语言代码。  
**UX 影响**: 浏览器翻译工具、屏幕阅读器可能无法正确处理页面语言。  
**修复**: 统一使用 `lang="zh-CN"`。

### 17. 悬浮球文档功能可见性差 ✅ 已修复
**文件**: `templates/base.html`（第 332-348 行）  
**问题**: 右下角悬浮球（文档入口）用途不够直观，用户难以发现。  
**UX 影响**: 重要的 debugtalk 函数文档入口被忽视。  
**修复**: 添加首次访问的引导提示（onboarding tooltip）。

### 18. 密码修改表单无 `autocomplete` 属性 ✅ 已修复
**文件**: `templates/auth/password_change_form.html`（第 33-39 行）  
**问题**: 密码输入框未设置 `autocomplete="current-password"` 和 `autocomplete="new-password"`。  
**UX 影响**: 浏览器无法自动填充密码，用户需手动输入。  
**修复**:
```html
<input type="password" name="old_password" autocomplete="current-password">
<input type="password" name="new_password1" autocomplete="new-password">
```

## 🟢 低优先级 / 建议改进 (Low)

### 19. 表格英文术语混入中文界面 ✅ 已修复
**多处**: `test_case_form.html` — "Add Parameter"、"Add Header"、"Bulk Edit"、"Description"、"Presets"  
`test_case_list.html` — "No test results yet"、"Run Test Now"  
**问题**: 中英混杂。  
**建议**: 统一为中文："添加参数"、"批量编辑"、"描述"。

### 20. 页面标题术语不一致 ✅ 已修复
**对比**: `project_detail.html` 标题 `"项目详情: {{ project.name }}"`  
vs `test_suite_list.html` 过滤信息 `"过滤项目: {{ project.name }}"`  
**问题**: 相同概念有时用"过滤"有时用"筛选"。  
**建议**: 统一使用"筛选"。

### 21. 卡片悬停动画对性能敏感 ✅ 已修复
**文件**: `templates/base.html`（第 124-127 行）  
**问题**: `.card:hover` 使用 `transform: translateY(-5px)`，在大量卡片页面（如测试结果列表）可能引起重排。  
**建议**: 仅使用 `box-shadow` 变化，避免 transform。

### 22. Alert 消息 5 秒自动关闭 ✅ 已修复
**文件**: `templates/base.html`（第 828-837 行）  
**问题**: 所有 alert 5 秒后自动关闭。对于错误消息用户可能来不及阅读。  
**建议**: 仅 success 类自动关闭，error/danger 消息保持可见直到用户手动关闭。

### 23. 测试运行自动刷新过度 ✅ 已修复
**文件**: `templates/test_manager/test_run_detail.html`（第 584-587 行）  
**问题**: Running 状态每 5 秒全页刷新。如果测试运行很长（>5 分钟），浪费带宽和服务资源。  
**建议**: 改为 AJAX 局部刷新仅更新进度条/结果。

### 24. Vue 页面缺少过渡动画 ✅ 已修复
**文件**: 所有 Vue 页面  
**问题**: Element Plus 列表/表格切换时无任何过渡动画。  
**建议**: 添加 `<transition>` 包裹路由切换。
