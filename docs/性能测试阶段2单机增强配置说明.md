# 性能测试阶段2 — 单机增强：`extra_config` 与 CSV 说明

本文档描述 `PerformanceTestTask.extra_config` 与 `csv_file` 字段的约定，适用于阶段2（单机 Locust），与阶段3分布式扩展解耦。

## 1. `extra_config` 顶层字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `timeout` | 整数（秒） | HTTP 超时，默认 30 |
| `think_time_ms` | 整数 | 每次请求结束后休眠毫秒数，默认 0 |
| `stages` | 数组 | 多阶段负载；缺省则使用 `total_users` / `spawn_rate` / `run_time` |
| `assertions` | 数组 | 业务断言；缺省则仅按 HTTP 状态码判定失败 |
| `csv_read_strategy` | 字符串 | `per_iteration`（每请求一行，默认）或 `per_user`（每虚拟用户固定一行） |

## 2. 多阶段负载 `stages`

```json
[
  {"duration_sec": 60, "users": 10, "spawn_rate": 1},
  {"duration_sec": 120, "users": 50, "spawn_rate": 2}
]
```

- 各阶段 `duration_sec`、`users`、`spawn_rate` 均为**正整数**。
- **所有阶段 `duration_sec` 之和必须等于任务的 `run_time`（秒）**。
- 实现方式：Locust `LoadTestShape.tick()` 按已运行时间切换阶段，由 `runner.start_shape()` 驱动；**不重启进程**，统计数据连续。

## 3. 业务断言 `assertions`

```json
{
  "assertions": [
    {"jsonpath": "$.code", "op": "eq", "expect": 200},
    {"jsonpath": "$.data.id", "op": "not_null"}
  ]
}
```

### 支持的操作符

| op | 说明 | expect |
|----|------|--------|
| `eq` | 等于 | 必填 |
| `ne` | 不等于 | 必填 |
| `gt` `ge` `lt` `le` | 数值比较 | 必填（数值） |
| `not_null` | 路径存在且值非 null | 不需要 |
| `contains` | 字符串包含 | 必填（子串） |

使用 [jsonpath-ng](https://pypi.org/project/jsonpath-ng/) 语法。断言在**收到响应体之后**执行，不改变 Locust 对响应时间的统计方式。

## 4. CSV 参数化

- 模型字段：`PerformanceTestTask.csv_file`（可选），扩展名 `.csv`，大小建议 ≤ 10MB（接口校验）。
- 占位符：`{{列名}}`，出现在 query / header / body 的字符串中；支持嵌套 JSON。
- `csv_read_strategy`：
  - `per_iteration`：全局轮询，每发一次请求取下一行（协程安全锁）。
  - `per_user`：每个虚拟用户在 `on_start` 分配固定行号，全程使用该行的数据。

## 5. 错误分类 `PerformanceTestResult.error_classification`

采样时写入各类型**累计次数**快照，键包括：

- `http_status_error`：HTTP ≥ 400 或由 `catch_response` 标记的 HTTP 失败
- `timeout`：请求超时
- `connection_error`：连接类错误
- `assertion_failure`：业务断言失败或非 JSON 导致无法断言

## 6. 阶段3（分布式）扩展点

- 可在 `extra_config` 增加 `worker_nodes`、`master_host` 等字段；执行入口建议新建 `run_locust_distributed()`，**勿与**单机 `LoadTestShape` 混在同一分支。

## 7. 数据与更新频率

- 时序采样仍为**约 1 秒/条**（`PerformanceTestResult`），与阶段1一致；报告接口对多采样做聚合（最大/平均等）。
