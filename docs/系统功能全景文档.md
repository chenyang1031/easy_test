## 1. 平台总览与价值主张

### 1.1 平台定位

EasyTesting 是一个面向测试团队和研发团队的 **API 接口全生命周期测试管理平台**，覆盖从接口定义、用例生成、场景编排、执行调度到结果分析的完整流程。平台采用前后端分离架构，后端以 Django REST Framework 提供 RESTful API，前端为多个 Vue 3 SPA 子应用。

### 1.2 核心价值矩阵

| 痛点 | 解决方案 | 价值点 |
|------|---------|--------|
| 接口文档散落、维护难 | 接口资产中心化管理 | **一处定义，多处复用** — 接口信息统一管理，场景编排自动同步，变更可追溯可回滚 |
| 测试用例编写重复劳动 | AI 智能生成测试用例 | **AI 替代人工** — 基于接口定义自动生成参数验证/业务逻辑/边界/安全等多维度用例 |
| API 文档迁移繁琐 | 文档导入一键生成 API | **文档即资产** — 上传 .docx/.md 接口文档，AI 自动提取 API 定义，一键导入资产库 |
| 多步骤业务流程难测试 | 可视化场景编排 | **拖拽式编排，所见即所得** — 将多个 API 节点连接成完整业务流程 |
| 性能测试门槛高 | 一键式性能压测 | **降低性能测试门槛** — 选择接口、配置并发数即可发起压测 |
| 回归测试依赖手工 | 定时任务自动化 | **无人值守自动回归** — 定时执行测试场景，失败自动告警 |
| 线上流量无法复用 | 流量回放导入 | **录回去、跑起来** — GoReplay/HAR 流量直接导入为测试场景 |
| 测试报告制作耗时 | 一键报告导出 | **报告自动生成** — HTML/PDF/JSON 报告，无需人工整理 |
| 测试数据准备繁琐 | Mock 数据生成 | **一键生成真实模拟数据** — 15 种数据类型覆盖常见场景 |

## 2. 项目管理

### 2.1 功能说明

项目是系统中最顶层的组织单元，所有测试资源（环境、用例、场景、报告等）均归属于项目。

- **项目创建**：填写项目名称和描述
- **项目列表**：查看所有项目，支持搜索筛选
- **项目编辑/删除**：修改或删除项目及其关联数据
- **项目关联**：每个项目可关联一个接口资产项目（ApiProject），实现业务与接口的双层映射

### 2.2 价值点

- **业务隔离，权责分明** — 不同业务线使用不同项目，互不干扰
- **资源聚合，管理便捷** — 一个项目集中管理所有测试资源
- **双层架构** — 平台项目（Project）→ API 项目（ApiProject），满足复杂组织需求

## 3. 环境管理

### 3.1 功能说明

环境管理为测试提供运行时上下文，支持多环境切换。

- **环境创建**：为项目创建测试环境（开发/测试/预发布/生产等）
- **Base URL 配置**：设置环境的基础 URL
- **变量管理**：定义 JSON 格式的环境变量，支持 `{{变量名}}` 模板引用
- **请求头预设**：设置该环境下的全局请求头
- **环境分类**：分为"默认环境"和"第三方环境"，支持全局可见开关
- **前置脚本**：为环境配置 JavaScript 前置脚本
- **前置脚本测试**：提供在线测试前置脚本的功能

### 3.2 价值点

- **一套用例，多环境运行** — 开发、测试、预发环境一键切换
- **环境变量统一管理** — 敏感信息集中存放，降低泄露风险
- **前置脚本自动化** — 令牌刷新、签名计算等自动完成

## 4. 接口资产管理

### 4.1 功能说明

接口资产管理是平台的核心资产中心，集中管理所有 API 接口的定义、分组、版本和变更。

#### 4.1.1 接口项目（ApiProject）

- 独立的接口资产项目，可与平台项目绑定
- 支持多级从属关系

#### 4.1.2 接口分组（ApiGroup）

- 树形层级结构，无限级分组
- 支持排序，方便组织

#### 4.1.3 接口资产（ApiAsset）

- **基本信息**：接口名称、请求方法（GET/POST/PUT/DELETE/PATCH）、URL 路径
- **请求参数**：结构化参数数组，含名称/类型/必填/默认值/描述/校验规则
- **请求头/请求体**：支持 JSON、Form-Data 格式
- **响应 Schema / 错误码 / 认证配置**
- **接口状态**：draft（草稿）/ active（启用）/ deprecated（弃用）
- **来源追踪**：manual / postman / apifox / openapi / goreplay / ai_document
- **软删除机制**：is_deleted 标记实现安全删除

#### 4.1.4 接口导入导出

- **Postman 导入**：解析 Postman Collection JSON
- **Apifox 导入**：支持 Apifox 格式导入，含环境配置
- **OpenAPI/Swagger 导入**：标准 OpenAPI 规范
- **接口导出**：导出为 JSON 文件

#### 4.1.5 接口历史与变更管理

- **操作历史（ApiHistory）**：记录所有变更操作（create/update/rollback）
- **变更记录（ApiAssetChangeRecord）**：before/after 快照对比，精确到字段级别
- **变更通知**：关联场景节点自动收到变更提醒

#### 4.1.6 接口预设（ApiPreset）

- 可复用的请求头/参数/表单数据模板
- 从预设快速填充到接口配置中

#### 4.1.7 接口草稿箱（ApiAssetDraft）

- 临时存储未完成的接口编辑
- 自动过期机制

### 4.2 价值点

- **接口即资产** — 统一管理降低沟通成本
- **生命周期清晰** — 草稿→启用→弃用，状态一目了然
- **导入即用，零迁移成本** — 支持三大主流格式
- **变更可追溯，回滚有保障** — 每次修改有历史记录
- **多源追踪** — 标记接口来源，全链路可追溯

## 5. 传统用例管理

### 5.1 功能说明

传统的测试用例管理模块，支持单接口用例的增删改查、分组管理和批量执行。

#### 5.1.1 用例分组（TestCaseGroup）

- 树形层级分组，无限级嵌套

#### 5.1.2 测试用例（TestCase）

- **基本信息**：名称、描述、分组
- **请求配置**：方法、URL、请求头（JSON）、请求体（JSON/Form-Data）
- **预期状态码**：期望的 HTTP 状态码
- **校验规则**：JSONPath 格式断言规则
- **参数提取**：从响应中提取变量
- **文件上传**：支持上传文件字段
- **超时设置**：自定义请求超时

#### 5.1.3 测试套件（TestSuite）

- 将多个测试用例按顺序组合为测试套件
- 每个用例可单独指定运行环境
- 树形分组管理

#### 5.1.4 测试执行（TestRun / TestSuiteRun）

- 单用例执行 / 批量执行
- 执行状态追踪：pending → running → completed/failed
- 执行计时

#### 5.1.5 测试结果（TestResult）

- 状态：passed / failed / error / skipped
- 完整请求/响应详情
- 提取参数 / 校验结果 / 响应时间

### 5.2 价值点

- **分层管理，结构清晰** — 分组→用例→套件三层结构
- **参数提取与传递** — 模拟真实业务流程
- **批量执行提升效率** — 一键执行整个套件

## 6. 测试场景编排（核心模块）

### 6.1 功能说明

测试场景编排是平台的核心能力，提供可视化的多步骤业务流程测试。

#### 6.1.1 测试场景（TestScene）

- 基于 API 项目创建场景
- 场景变量池、运行时配置
- 场景复制、软删除

#### 6.1.2 场景节点（TestSceneNode）

- **API 绑定**：关联接口资产
- **请求覆盖**：节点级别覆盖 URL/方法/头/参数/体
- **断言规则**：多条 JSONPath 断言
- **参数提取**：变量池机制，传递到后续节点
- **预期校验**：状态码/响应头/响应体
- **超时配置**：节点级超时
- **失败策略**：stop（停止）/ continue（跳过继续）
- **前置脚本**：节点级 JavaScript 脚本
- **环境绑定**：节点可单独指定运行环境
- **启用/禁用**：临时禁用节点
- **排序调整**：拖拽调整顺序

#### 6.1.3 API 资产同步

- **变更检测**：自动检测关联接口的变更
- **Diff 预览**：展示新旧差异对比
- **同步执行**：一键同步最新定义
- **72 小时回滚**：支持回滚到同步前状态
- **同步日志（TestSceneNodeSyncLog）**：完整审计记录

#### 6.1.4 可视化场景设计器（Vue 3 SPA）

- **三栏布局**：左侧资产树 → 中间节点列表 → 右侧配置面板
- **实时保存状态指示器**
- **环境选择器**：设计器中切换环境
- **变量池可视化**
- **节点图形化**：方法标签、断言数、提取数

#### 6.1.5 场景执行引擎

- **执行模式**：全流程（all）/ 单节点（single）
- **结果状态**：running / success / failed / partial_success
- **节点结果**：请求/响应详情、断言结果、提取变量、耗时
- **执行日志**：详细节点日志面板

#### 6.1.6 场景执行历史

- 历史执行记录列表
- 完整节点级结果
- 支持重新执行

### 6.2 变量传递机制

```
┌─────────┐     提取变量 A      ┌─────────┐     提取变量 B      ┌─────────┐
│ 节点 1  │ ─────────────────→  │ 节点 2  │ ─────────────────→  │ 节点 3  │
│ 登录    │   {{auth_token}}    │ 查询列表 │   {{order_id}}     │ 提交订单 │
└─────────┘                     └─────────┘                     └─────────┘
```

**变量系统关键能力**：

- **四层变量池**：debugtalk 函数 → 场景变量 → 运行时变量 → 环境变量，按优先级层叠覆盖
- **{{}} 模板语法**：节点配置和断言规则中支持 `{{var}}`、`{{func()}}`、`{{scene.var}}`、`{{env.var}}`、`{{node_id.xxx}}` 等引用方式
- **裸模板 JSON 支持**：节点 JSON 编辑器中可直接写入裸 `{{var}}` 无需引号包裹，前端自动转换为合法 JSON
- **增强错误提示**：变量解析失败时精确标识故障字段（如 `「断言规则-状态码校验」中变量解析失败: 变量路径不存在: time`）
- **更多细节**：参见 `docs/平台功能流程_API资产与测试场景编排.md` 第 5 节

### 6.3 价值点

- **可视化编排，零编码** — 拖拽式设计器
- **场景即流程** — 变量传递真实还原业务链路
- **接口资产双向同步** — 变更自动检测，72 小时回滚保障
- **精准断言全覆盖** — 断言 + 提取 + 预期校验三维验证
- **一人编排，团队复用** — 积累自动化测试资产库

## 7. AI 智能测试生成

### 7.1 功能说明

AI 智能测试生成模块通过大语言模型（LLM），基于接口定义自动生成高质量的测试用例。

#### 7.1.1 AI 模型提供商（AIModelProvider）

- **支持多种模型**：OpenAI 兼容、智谱 AI（Zhipu）、DeepSeek、自定义
- **灵活配置**：
  - Base URL + API Path：自定义接口地址
  - API Key：模型认证密钥
  - Model Name：选择具体模型（如 gpt-4o, deepseek-chat）
  - System Prompt：系统级提示词
  - Prompt Template：支持变量替换（{method}, {url}, {headers}, {body_schema}, {rules_text} 等）
  - Temperature / Max Tokens / Timeout：生成参数控制
- **启用/禁用 + 默认模型**控制

#### 7.1.2 测试用例生成规则（TestCaseGenerationRule）

六大规则分类，覆盖全面测试维度：

| 规则类别 | 说明 | 示例 |
|---------|------|------|
| `param_validate` | 参数校验 | 必填参数缺失、类型错误、长度越界 |
| `biz_logic` | 业务逻辑 | 重复提交、状态冲突、依赖不满足 |
| `error_handle` | 异常处理 | 服务器错误、超时处理、降级策略 |
| `boundary` | 边界值 | 数值边界、字符串长度边界、分页边界 |
| `security` | 安全测试 | SQL注入、XSS、未授权访问、参数篡改 |
| `performance` | 性能测试 | 大数据量、频繁请求、并发操作 |

- **规则分级**：high / medium / low
- **启用控制**：灵活开关
- **规则关联**：生成时记录使用了哪些规则

#### 7.1.3 AI 用例生成执行

- **单接口生成**：选定一个接口，AI 自动分析生成多维度用例
- **多类型同时生成**：一次生成可选多种用例类型
- **生成过程**：读取接口定义 → 组合提示词 → 调用 AI → 解析响应 → 结构化用例
- **频率限制**：每小时 10 次（ai_generate throttle）

#### 7.1.4 草稿箱（Draft Box）

- **用例草稿分组（AICaseDraftGroup）**：按接口和用例类型组织
- **AI 用例草稿（AICaseDraft）**：完整用例数据和生成来源
- **有效性校验**：自动校验 AI 生成的用例
- **导入状态追踪**：pending / partial_imported / imported
- **批量操作**：勾选 → 验证 → 一键导入为正式用例

#### 7.1.5 AI 生成记录（AIGenerationRecord）

- **完整审计**：记录每次 AI 请求的提示词、响应原文、用例类型、接口信息
- **性能统计**：耗时、用例数量
- **模型溯源**：关联使用的模型提供商

### 7.2 操作流程

```
① 配置 AI 模型提供商 → 填写 API Key / 选择模型 → 启用
② 配置用例生成规则 → 按需开启规则分类 → 设置优先级
③ 配置提示词模板（可选，有默认模板）
④ 进入接口资产管理 → 选中接口 → 点击"AI 生成"
⑤ 选择用例类型 → 确认生成
⑥ 进入草稿箱 → 查看生成的用例 → 校验有效性
⑦ 选中有效用例 → 一键导入为正式测试用例
⑧ 在生成记录中查看历史生成详情
```

### 7.3 价值点

- **AI 替代人工，效率提升 10 倍** — 接口定义即输入，AI 秒级生成多维度用例
- **测试维度全覆盖** — 六大规则类目全面覆盖
- **草稿箱审核机制，质量可控** — AI 辅助而非取代人工决策
- **规则越用越聪明** — 规则可沉淀为团队知识库

## 8. 文档导入 API 生成（新增）

### 8.1 功能说明

文档导入 API 生成模块支持上传 .docx/.md 接口文档，通过 AI 自动提取 API 接口定义，一键导入到 API 资产库。这是从"文档→API 资产"的 AI 自动化管道。

#### 8.1.1 文档上传与转换

- **支持格式**：.docx（Word 文档）和 .md（Markdown 文档）
- **文件大小**：最大 50MB
- **格式转换**：
  - .docx → pandoc 命令转换为 Markdown
  - .md → 直接读取文件内容（不做实质转换）
- **转换存储**：转换后的 Markdown 内容同时存储到数据库字段和磁盘副本

#### 8.1.2 AI 提取管道（Celery 异步）

```
上传文档 → 格式转换(md) → 存储转换内容 → AI 模型提取 API → 解析 JSON 结果 → 更新记录
```

- **异步执行**：通过 Celery 任务异步调用 AI，避免阻塞前端
- **默认模板**：自动使用 API 生成类别的默认提示词模板
- **快照机制**：执行时快照模型名和模板名，保证审计可追溯

#### 8.1.3 生成记录（DocumentGenRecord）

- **状态追踪**：uploading → converting → generating → success / failed
- **提取结果**：extracted_apis 存储 AI 提取的 API 列表
- **原始响应**：response_raw 保存 AI 原始响应
- **耗时统计**：duration_ms 记录 AI 调用耗时

#### 8.1.4 导入预览与确认

- **冲突检测**：按 url + method 检测与已有资产的冲突
- **预览/确认两步流程**：
  1. POST `/preview-import/` — 预览冲突
  2. POST `/confirm-import/` — 确认导入
- **冲突策略**：
  - skip（跳过重复）
  - overwrite（覆盖更新）
  - keep_both（同时保留）
- **自动分组**：导入的 API 默认归入"AI文档导入"分组

#### 8.1.5 重新生成

- 支持对已有记录直接重新调用 AI 提取（跳过上传和转换步骤）
- 重置导入状态为 pending

### 8.2 操作流程

```
① 进入文档导入页面 → 点击"上传文档"
② 填写任务名称 → 选择 API 项目 → 上传 .docx/.md 文件
③ 选择 AI 模型（可选，自动使用默认模型）
④ 选择提示词模板（可选，自动使用 API 生成默认模板）
⑤ 点击"开始生成" → 系统上传 → 转换 → AI 提取（异步）
⑥ 任务列表中查看结果 → 点击"查看 API"预览提取结果
⑦ 点击"导入" → 预览冲突 → 选择冲突策略 → 确认导入
⑧ 生成的 API 出现在接口资产管理中
```

### 8.3 价值点

- **文档即资产，零手工录入** — 上传 API 文档，AI 自动提取接口定义，告别逐条复制粘贴
- **支持主流文档格式** — .docx（Word 输出）和 .md（技术文档）全覆盖
- **冲突检测保证数据安全** — 导入前自动检测重复接口，skip/overwrite/keep_both 三种策略
- **异步执行不阻塞** — Celery 后台处理，前端操作流畅无等待
- **完整审计追溯** — 每次生成记录保存完整 prompt/response/模型/模板信息

## 9. AI 提示词模板管理（新增）

### 9.1 功能说明

AI 提示词模板管理模块提供对 AI 生成所需提示词的集中管理和版本控制，支持用户创建、编辑、启用/禁用提示词模板。

#### 9.1.1 模板分类（PromptTemplate）

- **API 生成（api_gen）**：用于文档导入时提取 API 接口，变量 `{document_content}` 代表文档内容
- **用例生成（test_case_gen）**：用于 AI 生成测试用例，变量如 `{method}`, `{url}`, `{headers}` 等

#### 9.1.2 模板管理功能

- **创建/编辑/删除**：完整 CRUD 操作
- **默认模板**：每种分类一个默认模板，系统内置"API文档提取（默认）"
- **启用/禁用**：灵活开关模板
- **系统模板**：created_by=null 表示系统内置模板，所有用户可见不可删
- **变量替换**：`to_rendered_prompt(context)` 方法实现模板变量替换

#### 9.1.3 权限设计

- 用户可看到自己创建的模板 + 系统内置模板（created_by__isnull=True）
- 系统模板防止误删

### 9.2 操作流程

```
进入 AI 提示词管理 → 查看已有模板 → 创建新模板 → 填写名称/内容 → 设为默认（可选）→ 保存
                                    → 编辑模板 → 修改内容 → 保存
                                    → 删除自定义模板
```

### 9.3 价值点

- **提示词即资产** — 好的提示词可沉淀、复用、迭代
- **多模板灵活切换** — 不同文档/接口使用不同提示词策略
- **系统默认兜底** — 系统内置模板确保不配置也能正常使用

## 10. 性能/负载测试

### 10.1 功能说明

性能/负载测试模块基于 Locust 引擎，提供一键式 API 接口压力测试能力。

#### 10.1.1 性能测试任务（PerformanceTestTask）

- **基本信息**：任务名称、所属项目
- **目标接口**：选择要压测的 API 接口
- **并发配置**：总用户数 / 孵化速率 / 运行时间
- **目标 RPS 限流**：设置每秒请求数上限
- **CSV 参数化**：支持 CSV 文件驱动的参数化
- **多阶段负载配置**：stages 参数配置阶梯式负载
- **断言配置**：JSONPath 格式的业务断言
- **任务状态**：draft → running → completed / stopped / failed
- **执行人追踪**：创建人/停止人完整审计

#### 10.1.2 执行引擎

- **运行模式**：
  - 子进程模式（默认）：本地 Locust 子进程
  - Celery 模式：通过 Celery Worker 后台执行
- **优雅停止**：手动停止，记录停止原因和操作人
- **异常诊断**：诊断无数据/卡死/异常退出

#### 10.1.3 实时结果（PerformanceTestResult）

- **采样频率**：每 3 秒采集一次
- **核心指标**：活跃用户数、QPS、P50/P90/P95/P99、最大响应时间、错误率
- **错误分类统计**：http_status_error / timeout / connection_error / assertion_failure

#### 10.1.4 性能报告与可视化

- **汇总统计**：总请求数、总失败数、平均 QPS
- **延迟分布**：详细百分位延迟
- **时间序列图表**：QPS 和响应时间随时间变化趋势
- **实时控制台**：压测过程中实时图表监控

### 10.2 价值点

- **零门槛性能测试** — 选接口、设并发、开始压测
- **阶梯式负载，安全渐进** — 从低到高逐步加压
- **实时监控，秒级洞察** — QPS/延迟/错误率实时刷新
- **结果可沉淀可对比** — 不同版本间性能指标可对比

## 12. 前置脚本引擎

#### 12.1.1 脚本层级

| 级别 | 作用范围 | 适用场景 |
|------|---------|---------|

- **CryptoJS**：MD5、SHA1、SHA256、AES 等加密库
- **安全性**：子进程隔离、超时保护（默认 1000ms）、沙箱执行

### 12.2 价值点

- **动态参数实时计算** — 签名、时间戳等自动计算
- **Postman 兼容语法** — 零学习成本迁移
- **三级作用域，灵活可控** — 节点级、环境级自由组合
